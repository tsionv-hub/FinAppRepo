# תכנון פיננסי

**[English](README.md)**

אפליקציה לטלפון (אייפון ואנדרואיד) לתכנון הכסף שלכם. היא מראה כמה שווים החסכונות שלכם אחרי מס, כמה אפשר להוציא היום, והאם היעדים, הפרישה המוקדמת, ההלוואות והפנסיה מכוסים. היא גם עוקבת אחרי הפקדות והענקות מניות, ומשווה את הקופות שלכם לתשואות הרשמיות שלהן.

המספרים נשארים **בגיליון Google שלכם**. אין שרת ואין מעקב: הנתונים עוברים רק בין הטלפון שלכם לבין Google. שתי תוספות (לא חובה): אם ממלאים מספרי קופות, רק המספרים האלה נשלחים ל-data.gov.il כדי להביא נתונים ציבוריים על הקופות; והצ'אט **שאלו את ה-AI** שולח את השאלה והגיליון ל-Google Gemini, רק אחרי שאישרתם.

## שימוש באפליקציה

- **פעם ראשונה? מתחילים כאן: [איך מתחילים](docs/START.he.md)**
- המדריך המלא: [המדריך המלא](docs/MANUAL.he.md)
- רק רוצים להציץ? פתחו את האפליקציה ולחצו **לחקור עם נתוני דוגמה**. לא צריך להתחבר.

## מה רואים באפליקציה

| חלק | מה הוא מראה |
|---|---|
| **אחרי מס היום** | כל מה שיש לכם, פחות המס שהייתם משלמים אילו מכרתם הכול עכשיו. בלי פנסיה. מתחת: **אחרי חובות**. |
| **כסף פנוי היום** | כמה אפשר להוציא **עכשיו**, ועדיין לממן כל יעד בזמן ולשמור על הקרן ליום סגריר. |
| **תחזית** | הכסף שלכם לאורך זמן, עם תרחיש תשואה (אופטימי, מתון, פסימי) ופס תאריך. |
| **יעדים** | כל יעד, מתי ובכמה, והאם הוא במסלול. יעד יכול לחזור (למשל חופשה כל שנה). |
| **פנסיה** | כמה הקרנות עשויות לשלם בחודש, אחרי מס. |
| **הלוואות** | כמה עוד חייבים, תוכנית ההחזר והאם היא במסלול. |
| **נכסים** | כל החשבונות, במקטעים לפי סוג (קרנות השתלמות, קופות, מסחר, בנק, מניות, פנסיה), ובתחתית תרשים של התשואות הרשמיות. |

לחיצה על כל חשבון, הלוואה או יעד פותחת חלון עם פרטים. בחלון של נכס אפשר גם להוסיף הפקדה, לעדכן יתרת בנק או להוסיף הענקת מניות.

## פרטיות

- המספרים עוברים רק בין הטלפון שלכם לגיליון שלכם.
- מי ששלח לכם את האפליקציה **לא** יכול לראות את הגיליון או את המספרים שלכם.
- האפליקציה כותבת לגיליון רק כשלוחצים על כפתור שמירה.
- אם ממלאים מספרי קופות, רק המספרים נשלחים ל-data.gov.il (נתונים ציבוריים). לא סכומים, לא שמות ולא מספרי חשבון.

ההוראות הטכניות (פרסום ב-GitHub Pages, התחברות Google, הוספת חברים) נמצאות ב-[`docs/SETUP.md`](docs/SETUP.md), באנגלית.
