# תכנון פיננסי: איך מתחילים

**[English](START.md)**

תכנון פיננסי מראה כמה שווה הכסף שלכם אחרי מס, כמה אפשר להוציא היום, והאם התוכניות לעתיד מכוסות. המספרים נמצאים **בגיליון Google שלכם**. אף אחד אחר לא רואה אותם, גם לא מי ששלח לכם את האפליקציה.

---

## שלב 1. מציצים (דקה, בלי התחברות)

1. פתחו את הקישור לאפליקציה שקיבלתם.
2. לחצו **לחקור עם נתוני דוגמה**.
3. הסתובבו: הזיזו את פס התאריך, לחצו על חשבון או יעד כדי לראות פרטים.

שום דבר לא נשמר. בסיום לחצו **יציאה מהדוגמה**.

---

## שלב 2. מבקשים להצטרף (פעם אחת)

שלחו את **כתובת ה-Gmail** שלכם למי ששיתף את האפליקציה. הוא יוסיף אתכם כבודקים. עד אז Google לא יאפשר להתחבר.

---

## שלב 3. מכינים גיליון (5 דקות, הכי נוח במחשב)

1. באפליקציה לחצו **הורדת גיליון הדוגמה** (מספרים מומצאים) או **הורדת תבנית ריקה**.
2. היכנסו ל-**drive.google.com** ← **חדש** ← **העלאת קובץ** ← בחרו את הקובץ.
3. פתחו אותו, ואז **קובץ** ← **שמירה כ-Google Sheets**. *(האפליקציה לא יכולה לקרוא את גרסת ה-Excel.)*
4. הכניסו את המספרים שלכם. את שמות הלשוניות ואת כותרות העמודות **השאירו בדיוק כמו שהם** (באנגלית).

---

## שלב 4. מתקינים את האפליקציה בטלפון

**אייפון:** פתחו את הקישור ב-**Safari** ← **שיתוף** ← **הוספה למסך הבית** ← **הוספה**.

**אנדרואיד:** פתחו את הקישור ב-**Chrome** ← **⋮** ← **הוספה למסך הבית** (או **התקנת אפליקציה**) ← **התקנה**.

מעכשיו **פותחים תמיד מהסמל** במסך הבית.

---

## שלב 5. מחברים את הגיליון

1. ב-Google Sheets פתחו את הגיליון ← **שיתוף** ← **העתקת קישור**.
2. באפליקציה הדביקו את הקישור, תנו לגיליון כינוי (למשל *בית*) ← **המשך**.
3. לחצו **המשך עם Google** ובחרו את החשבון שלכם.
4. Google יכתוב **"Google לא אימתה את האפליקציה הזו"**. זה צפוי באפליקציה פרטית: לחצו **מתקדם** ← **מעבר אל Finance Planner (לא בטוח)** ← **המשך**.
5. **בדיקת הגיליון** מראה מה נמצא. כשליד הכול יש ✓, לחצו **פתח את התכנון**.

---

## ביום-יום

- פותחים מהסמל ← **המשך עם Google**. מתחברים בכל פעם בכוונה: האפליקציה לא שומרת התחברות בטלפון.
- שיניתם מספרים בגיליון? לחצו **רענון**.
- שינויים תחת **הנחות** הם רק "מה אם". האפליקציה כותבת לגיליון **רק** כשלוחצים על כפתור **שמירה**.
- הכפתור **English / עברית** למעלה מחליף שפה. אפשר להוסיף יעדים גם בעברית.

---

## משהו לא עובד?

| מה רואים | מה עושים |
|---|---|
| Google כותב **access denied** (אין גישה) | עוד לא הוסיפו אתכם: ראו שלב 2. |
| **"זה קובץ Excel"** | ב-Google Sheets: **קובץ** ← **שמירה כ-Google Sheets**, והשתמשו בקישור החדש. |
| **"חשבון Google הזה לא יכול לפתוח את הגיליון"** | התחברו עם החשבון שהגיליון שלו. |
| **✗** בבדיקת הגיליון | תקנו את שם הלשונית או העמודה בדיוק כמו שמופיע, ואז **בדוק שוב**. |
| חלון ההתחברות לא נפתח | במסך ההתחברות, לחצו **בדיקת התחברות** בתחתית, ואז **2. התחברות (הפניה)**. |
| גרסה ישנה | סגרו את האפליקציה לגמרי ופתחו שוב כשיש אינטרנט: היא מתעדכנת לבד. הגרסה מופיעה למעלה, ליד השם. |
